## Scope and migration decision

Nine portable cores cover ICM-42670-P, BME688, MPU6050, MAX86150, INA228, ICM-45605,
TSL2540/TSL2541, T5838 AAD control and Qwiic LED Stick. Shared NSX/Zephyr bus
adapters use the same production CMake targets as standalone CMake/FreeRTOS.
Zephyr has a BME688 T/P/H wrapper only; T5838 requires a board timing endpoint
and separate audio integration. The module does not provide generic physiological
metrics, lux calibration, BSEC/IAQ, advanced ICM processing or hardware accuracy.

This major version intentionally breaks v0 source use. Review the documented
header/target, context lifetime, explicit lifecycle and recovery migration;
recompile all callers and libraries together. The accepted source contract does
not promise binary ABI, stable context size/layout or serialized structs.
See [migration guidance](../migration/api-cleanup.md), the
[catalog](../../CATALOG.md) and [source contract](../v1-api-contract.md).

explicitly retained. [Hardware plan](../hardware-validation.md).
